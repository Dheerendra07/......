Song Configuration — Vaaroon (Mirzapur)
=======================================

Website me Mirzapur ka original song "Vaaroon" (Anand Bhaskar & Romy)
pehle se official embed ke saath juda hua hai — sirf "Vaaroon Suno" /
"वारूँ सुनें" button par tap karne par chalta hai (kabhi autoplay nahi hota).

Agar aap apna local MP3 file chalana chahein (offline ya direct audio ke liye):
1. Apni MP3 file ko is folder me rakhein (jaise: varoon.mp3).
2. js/content.js me SITE_CONFIG.music.src ko update karein:
   src: './assets/music/varoon.mp3'
